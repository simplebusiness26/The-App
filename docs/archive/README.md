# Archive

The files in this directory are superseded. They are kept for reference
only — history, prior decisions, old status reports, retired plans and
release notes for branches that no longer exist.

**Do not treat anything in here as a current instruction, a current
status, or a current plan.** If something in one of these files
disagrees with `CLAUDE.md`, `docs/SCREEN-INVENTORY.md`, or the current
code, the archive is wrong and the current file is right.

Current documentation lives at the repo root and in `docs/`, not here:
`CLAUDE.md`, `RULES.md`, `docs/SCREEN-INVENTORY.md`,
`docs/design-system.md`, and `docs/PLACE_FOLLOW_TEST_PLAN.md` /
`docs/MEMORIES_TEST_PLAN.md` (kept live because CI reads them).
